# MediPulse TV

An intelligent health and medication-adherence platform combining a large-screen Fire TV dashboard with an Alexa+ conversational assistant.

## Overview
MediPulse TV bridges the gap between healthcare management and the living room, helping users and caregivers track medication schedules through voice and big-screen visual reminders.

## Key Features
- **Big-Screen Dashboard:** High-contrast, easy-to-read medication schedules and health alerts displayed natively on Amazon Fire TV.
- **Conversational Voice AI:** Powered by Alexa+ to allow users or caregivers to check schedules and log doses using natural voice commands.
- **Serverless Backend:** Secure cloud architecture to manage real-time alerts and user schedules.

## Tech Stack
- **Frontend / TV UI:** Amazon Fire TV SDK / Web technologies
- **Voice Assistant:** Alexa+ Custom Skills
- **Backend:** AWS Serverless / Node.js & Python

## Getting Started
1. Clone the repository.
2. Configure your AWS and Alexa developer credentials.
3. Deploy the backend and launch the Fire TV interface.
